This is a full static Deobfuscator for Moonsec V3 and Moonsec V2

## requirements
- Python
- luaparser (python lib)

## setup
```git clone https://github.com/axom0022/moonsec-deobfuscator-byaxom.git```
```cd moonsec-deobfuscator-byaxom```
```pip install luaparser```

example usage :
```python3 deobf.py input.lua output.lua```

web version :
```python3 webapp.py 8000```
